# Idea

Replace manual ticket sales through messages, paper slips and spreadsheets with one flow: create an event, obtain approval, sell tickets, deliver QR tickets, admit each ticket once, and review results.

The initial audience is small and medium event organizers in Bangladesh: campus clubs, concerts, cultural events and workshops. The first release simulates mobile banking payments; no real money is collected.

Sources: PRD sections 1–2; build brief sections 0–1. This is a summary of supplied research, not independently validated market research.
