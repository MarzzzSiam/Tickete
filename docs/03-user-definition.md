# Users and journeys

| User | Primary need | MVP journey |
|---|---|---|
| Organizer / event owner | Sell tickets and coordinate entry | Verify email, draft event, submit, invite team, monitor, close |
| Platform admin | Review submitted events | Review, approve or reject with reason; receive notifications |
| Manager | Help operate one event | Edit permitted drafts, view attendees and reports, check in |
| Scanner | Admit attendees quickly | Accept invitation, select assigned event, scan or type ticket code |
| Viewer | Understand event performance | Read event dashboard and reports without attendee data |
| Registered buyer | Convenient purchase | Login, select tickets, pay, receive receipt and tickets |
| Guest buyer | Purchase without an account | Enter email, pay, retrieve later using emailed OTP |
| Gift recipient | Receive and use a ticket | Receive PDF; prove email access to retrieve tickets |

Global account role does not grant access to another organizer's event. Event ownership and accepted team membership determine event permissions. Buyers and organizers can buy tickets; team roles are scoped to individual events.
